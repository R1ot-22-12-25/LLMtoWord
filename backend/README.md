# 🖥️ LLMtoWord 本地离线 OCR Sidecar 微服务

本项目为 **LLMtoWord** 前端提供可选的**完全本地离线、零成本、无需联网**的数学公式视觉识别支撑。

---

## 🌟 核心特性
- **模型轻量**：默认采用开源明星模型 **`LaTeX-OCR (pix2tex)`**，模型权重仅约 **110MB**；
- **低硬件门槛**：纯 CPU 笔记本即可在 **0.2 ~ 0.4 秒** 内完成公式识别，无需独立显卡；
- **全自动连接**：启动后，前端 Web 界面会自动嗅探探测 `http://127.0.0.1:8000` 并无缝切换为本地离线模式；
- **隐私保护**：所有公式图片与代码均在本地内存处理，100% 不上传任何云端服务器。

---

## 🚀 极速启动指南

### 方式 1：一键双击启动（Windows 推荐）
直接双击运行目录下的 **`start.bat`** 即可，脚本会自动检测依赖并拉起服务。

### 方式 2：命令行手动启动

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 启动服务
python app.py
```

服务就绪后会监听：`http://127.0.0.1:8000`
- 健康检查：`GET http://127.0.0.1:8000/api/health`
- 接口文档：`http://127.0.0.1:8000/docs`
- 识别接口：`POST http://127.0.0.1:8000/api/ocr`

---

## 🔬 进阶：切换至 UniMERNet 模型（高精度学术公式）
若您需要识别极度长篇复杂的专业学术论文公式，可将 `app.py` 中的推理引擎替换为 **`UniMERNet`**（由中科院自动化所与 OpenDataLab 开源）：
```bash
pip install unimernet
```
相关模型权重会在初次运行时由 HuggingFace / ModelScope 自动缓存至本地目录。
